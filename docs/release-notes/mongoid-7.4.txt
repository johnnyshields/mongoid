Localized field ``*_translations.to_h`` now returns Symbol keys
---------------------------------------------------------------

**Breaking change:** When using fields with the ``localized: true`` option,
Mongoid provides access to all translations using an ``*_translations``
accessor. Beginning in Mongoid 7.4, this accessor returns a
``Mongoid::SymbolizedHashWithIndifferentAccess``. It behaves identically
to a HashWithDifferentAccess, except its underlying keys are Symbols rather
than Strings. This creates consistency with ``I18n.locale``, which returns a Symbol.

.. code-block:: ruby

  I18n.locale = :de

  Person.name = "Johannes Gutenberg"
  Person.name_translations #=> { de: "Johannes Gutenberg" }
                               (Mongoid::SymbolizedHashWithIndifferentAccess)

  Person.name_translations.to_h.key?(I18n.locale) #=> true
  Person.name_translations.to_h.key?(I18n.locale) #=> false

In Mongoid 7.3 and prior, this accessor returned an
``ActiveSupport::HashWithIndifferentAccess`` the uses Strings as its
underlying keys.

.. code-block:: ruby

  I18n.locale = :de

  Person.name = "Johannes Gutenberg"
  Person.name_translations #=> { "de" => "Johannes Gutenberg" }
                               (ActiveSupport::HashWithIndifferentAccess)

  Person.name_translations.to_h.key?(I18n.locale) #=> false
  Person.name_translations.to_h.key?(I18n.locale) #=> true
